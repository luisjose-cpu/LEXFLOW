# P5 Validation

## Automated Checks

Run the full validation suite:

```bash
npm run p5:check
```

This runs web lint, web tests, web build, and API tests.

## Backend Coverage

- Source creation and listing.
- Authorized adapter checks.
- Judicial update creation.
- Evidence creation.
- Approval and rejection flow.
- CAPTCHA pause flow.
- CAPTCHA checkpoint resolution.
- Tenant isolation.
- Audit logs.

## Frontend Coverage

- Judicial source panel.
- CAPTCHA state badge.
- Human-in-the-loop checkpoint modal.
- Source configuration form.
- Judicial update timeline.
