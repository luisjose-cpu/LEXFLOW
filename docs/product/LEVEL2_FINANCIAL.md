# LEVEL2 Engine Rentabilidad

Engine Rentabilidad da valor economico a cada expediente: honorarios, horas, gastos, presupuesto, facturado, pendiente, margen y ROI.

Endpoints:

- `GET /api/v1/financial/overview`
- `GET /api/v1/financial/cases/{case_id}`
- `POST /api/v1/financial/cases/{case_id}/expenses`
- `POST /api/v1/financial/cases/{case_id}/hours`

Ruta web: `/financial`.
