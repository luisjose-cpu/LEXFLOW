# Pilot Onboarding Checklist

## 1. Calificacion del estudio

- [ ] Confirmar sponsor socio.
- [ ] Confirmar responsable operativo.
- [ ] Confirmar 2 abogados usuarios.
- [ ] Confirmar 1 asistente.
- [ ] Confirmar 1 cliente controlado o usuario cliente simulado.
- [ ] Confirmar duracion del piloto.
- [ ] Confirmar criterios de exito.

## 2. Alcance

- [ ] Definir 3 a 5 expedientes piloto.
- [ ] Definir si son demo, anonimizados o reales.
- [ ] Definir documentos iniciales.
- [ ] Definir comunicaciones permitidas.
- [ ] Definir si IA usara solo mocks o proveedor preparado.
- [ ] Definir integraciones excluidas.

## 3. Configuracion tenant

- [ ] Crear tenant piloto.
- [ ] Crear usuario tenant admin.
- [ ] Crear usuarios abogado.
- [ ] Crear usuario asistente.
- [ ] Crear usuario cliente.
- [ ] Asignar roles y permisos.
- [ ] Configurar plan mock o plan piloto.

## 4. Carga inicial

- [ ] Crear clientes.
- [ ] Crear expedientes.
- [ ] Cargar documentos.
- [ ] Marcar visibilidad de documentos cliente.
- [ ] Crear audiencias.
- [ ] Crear tareas.
- [ ] Crear fuentes judiciales mock/autorizadas.
- [ ] Crear plantillas de mensaje.

## 5. Seguridad

- [ ] Verificar que cliente no ve otros clientes.
- [ ] Verificar que cliente no ve notas internas.
- [ ] Verificar que cliente no ve documentos privados.
- [ ] Verificar que IA requiere revision profesional.
- [ ] Verificar que acciones criticas generan audit log.
- [ ] Verificar que no hay credenciales reales en codigo.

## 6. Demo y entrenamiento

- [ ] Ejecutar demo de 7 a 10 minutos.
- [ ] Entrenar socio en dashboard.
- [ ] Entrenar abogado en Expediente 360.
- [ ] Entrenar asistente en tareas/documentos.
- [ ] Entrenar cliente en portal.
- [ ] Ejecutar Automation Studio dry run.

## 7. Operacion del piloto

- [ ] Definir canal de soporte.
- [ ] Definir horario de soporte.
- [ ] Definir responsable de feedback.
- [ ] Registrar incidencias.
- [ ] Revisar logs/auditoria semanalmente.
- [ ] Medir metricas de exito.

## 8. Cierre

- [ ] Demo final con aprendizajes.
- [ ] Comparar metricas contra baseline.
- [ ] Listar bloqueos.
- [ ] Listar mejoras.
- [ ] Decidir GO / ITERATE / NO GO.
