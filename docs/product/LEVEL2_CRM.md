# LEVEL2 Legal CRM

Legal CRM gestiona pipeline comercial:

Lead -> Contacto -> Reunion -> Propuesta -> Negociacion -> Ganado -> Cliente -> Expediente.

Endpoints:

- `GET /api/v1/crm/leads`
- `POST /api/v1/crm/leads`
- `PATCH /api/v1/crm/leads/{lead_id}/stage`
- `POST /api/v1/crm/leads/{lead_id}/convert`
- `GET /api/v1/crm/analytics`

Ruta web: `/crm`.
