# LEVEL4_DATA_PLATFORM

Legal Data Platform centraliza eventos juridicos para indexacion, memoria, busqueda, analytics y future ML.

## Pipeline

Event ingestion -> Unified indexer -> Memory index -> Analytics engine -> Future ML.

## Eventos

Expedientes, documentos, SINOE, IA, OCR, comunicaciones, audiencias, riesgos, KPIs, automation, graph y memory.

## Seguridad

Todos los eventos son tenant-scoped y usan idempotency key.
