# LEVEL3_AI_AGENTS

AI Agents Framework prepares specialized agents with JSON output, permissions, audit logs and review-required guardrails.

APIs:

- `GET /api/v1/agents/catalog`
- `POST /api/v1/agents/{agent_key}/run`

Agents: CaseAgent, DocumentAgent, HearingAgent, ClientAgent, NewsAgent, ManagementAgent and AutomationAgent.
