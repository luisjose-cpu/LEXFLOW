# P12 Billing SaaS

## Goal

Convert LEXFLOW into a sellable SaaS foundation with plans, limits, licenses, modules, onboarding, trial, mock subscription, usage, and invoice-ready records.

## Plans

- START: Expediente 360, client portal, dashboard, mobile PWA.
- PRO: START plus WhatsApp mock and judicial automation.
- AI: PRO plus practical legal AI, legal intelligence, and custom branding.
- ENTERPRISE: All feature gates plus custom domain and API access.

## Feature Gates

- expediente360
- client_portal
- whatsapp
- ai
- legal_intelligence
- judicial_automation
- dashboard
- mobile_pwa
- custom_branding
- custom_domain
- api_access

## User Surfaces

- `/pricing`
- `/onboarding`
- `/settings/billing`
- `/settings/usage`
- `/settings/features`

## Product Rule

Billing does not replace authorization. Feature gates define entitlement, while backend permissions still enforce access.
