# LEXFLOW Mobile

P1 prepares the mobile/PWA surface without committing to native delivery yet.

Future stack:

- Expo
- React Native
- TypeScript
- Shared design tokens
- Shared API types

Prepared screens:

- Login
- Home
- Cases
- CaseDetail
- Documents
- Notifications
- Profile

The current P1 package is intentionally lightweight. Native dependencies should be installed during the mobile implementation phase.
